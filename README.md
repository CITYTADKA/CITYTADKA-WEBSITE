# City Tadka — Website (v0.1)

This is the real, working start of the City Tadka website. It is already
connected to your live Supabase database — the homepage pulls real
categories and articles from it.

## What's in this first version
- Home page, reading live from your `categories` and `articles` tables
- Design system colours/fonts wired into Tailwind (matches the mockups)
- Supabase connection (browser + server) ready for every future page

## What's NOT built yet (coming next, in this order)
1. Coverage feed + article detail pages
2. Events + Razorpay checkout + QR tickets
3. City Tadka Club + offer claims
4. Editor dashboard (so you can actually publish content without me)
5. Login (phone OTP)

## You don't need to run any of this yourself
Once you have a Vercel account, I'll walk you through connecting this
project — Vercel builds and runs it automatically. You will never need to
type a command or "run" anything on your own computer.
